Easy Rentals Student Accommodation Management System

Project description:  
Easy Rentals currently manages accommodation enquiries and property viewings using manual WhatsApp communication. The landlord must communicate with each student individually, arrange separate viewing times, travel to the property for each viewing, and show rooms one student at a time. This process is time-consuming, costly due to repeated petrol expenses, difficult to manage, and inconvenient for current tenants who must accommodate strangers entering their private living spaces. Students also waste time and money travelling to view properties that may be unsuitable. The lack of a centralised system means there is no formal way for students to submit complaints, queries, or feedback, and no proper access control for sensitive information. An improved digital solution is therefore needed to make the accommodation viewing process more efficient, reduce unnecessary physical viewings, improve communication, and enable the stakeholder to identify areas for improvement through user feedback.

Technologies Used:
